# 주택파동 90초 데모 시나리오

## 0–10초 · 전체 화면

Dashboard를 열고 `MIXED DATA` 안내를 보여준다.

> “주택파동은 실제 공식 데이터와 시연 데이터를 구분해, 정책에서 입주까지의 공급 흐름을 한 화면에 보여줍니다.”

## 10–22초 · 6단계 Pipeline

Pipeline에서 POLICY부터 MOVE_IN까지의 흐름을 가리킨다.

> “단계별 숫자는 같은 의미가 아닙니다. 공급계획과 공급완료, 입주예정과 실제입주를 분리해 관리합니다.”

## 22–38초 · 지역·기관 필터와 LIVE 사업

기관을 LH, 지역을 경기 또는 인천으로 선택하고 실제 LH 사업을 연다.

> “수도권 LH 실제 Project Master 23건, 계획 공급 8,072호를 반영했습니다. LIVE 배지는 공식 실제 데이터입니다.”

## 38–52초 · Project Drawer

LIVE 사업 하나를 열어 계획 공급호수, 공급예정월, 출처를 확인한다.

> “좌표와 연결 근거가 없는 값은 만들어내지 않고 미확보로 표시합니다.”

## 52–66초 · 향후 일정과 지도

3/6/12개월 탭을 바꾸고 지도 안내를 보여준다.

> “향후 일정은 월 단위 공식 계획을 유지합니다. 실제 사업은 공식 좌표가 없어서 지도 marker를 임의 생성하지 않았습니다.”

## 66–80초 · Coverage와 연결 검토

Coverage 상세와 `연결 검토` 메뉴를 연다.

> “PARTIAL은 공식 source가 연결됐지만 사업·필드 연결이 완전하지 않다는 뜻입니다. 공고 후보는 자동 연결하지 않고 근거 기반 검토 대상으로 남깁니다.”

## 80–90초 · 마무리

> “주택 공급량뿐 아니라 어디까지 진행됐고, 어떤 데이터가 연결되지 않았는지까지 한눈에 확인할 수 있습니다.”
